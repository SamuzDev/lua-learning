# Lua Learning Project

A simple Lua project to practice Git operations:
- Branching
- Merging
- Reverting commits
- Rebasing
- Stashing

## Files
- `main.lua` - Entry point
- `hello.lua` - Greeting module
- `calculator.lua` - Basic math operations

## Practice Exercises
1. Create a feature branch: `git checkout -b feature/new-operations`
2. Add power/modulo functions to calculator
3. Commit and merge back to main
4. Practice `git revert` on a commit
5. Practice `git rebase` with a feature branch
6. Practice `git stash` for temporary changes
